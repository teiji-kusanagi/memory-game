# 神経衰弱

HTML・CSS・JavaScript だけで作った、ブラウザで遊べる神経衰弱ゲームです。

## 遊ぶ

https://teiji-kusanagi.github.io/memory-game/

## 遊び方

1. カードを2枚めくります。
2. 同じ絵柄ならそろって、表のまま残ります。違う絵柄なら、少しすると裏に戻ります。
3. 16枚（8組）を全部そろえたらクリアです。少ない手数を目指しましょう。

## 主な機能

- **シャッフル演出**：始めるときに、カードが混ざってから並びます。
- **コンボ演出**：続けてペアをそろえると「○ 連続!」と表示されます。
- **最少手数の記録**：一番少ない手数をブラウザに保存します。
- **タイマー**：1枚目をめくると、時間を計り始めます。
- **効果音**：めくる音、そろう音などが鳴ります。続けてそろえるほど、そろう音が高くなります。「音」ボタンでオン・オフを切り替えられます。
- **最初から**：ボタン1つで、いつでもやり直せます。

## 手元で動かす

`index.html` をブラウザで開くだけで遊べます。
